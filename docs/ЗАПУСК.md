# Запуск Scout: всё по шагам

Есть три способа. **A. На своём компьютере по кнопке** (ничего не нужно покупать, программа работает только пока вы её открыли). **A+. То же плюс свой сайт в облаке Cloudflare** (сайт и данные хранятся в облаке и открываются с телефона, а читает чаты и думает программа на вашем компьютере; бесплатно). **B. На сервере круглосуточно** (шаги 0–14 ниже).

## Быстрый старт на Windows: установщик (рекомендую)

1. Откройте https://github.com/maxbzd/lead-scout/releases, в самом верхнем выпуске скачайте **`Scout-Setup.exe`**.
2. Запустите его. Windows может написать «Неизвестный издатель» (программа не подписана платным сертификатом): нажмите «Подробнее» → «Выполнить в любом случае». Администратор не нужен, ставится в вашу папку.
3. Нажмите «Далее». Отметьте «Значок на рабочем столе» и, если хотите, «Запускать вместе с Windows».
4. Scout появится в меню «Пуск» и на рабочем столе. Нажмите на значок: откроется окно приложения.
5. Дальше мастер подсказок в самом приложении (Профиль → Подключения): Telegram, бот, ИИ, облачный сайт для телефона.

Обновления: в «Профиле» блок «Программа на компьютере» показывает версию. Когда выходит новая, в ленте появится баннер «Есть обновление», нажмите «Обновить»: программа сама скачает версию, проверит её, закроется и откроется уже новой. Данные и настройки не теряются. Там же кнопка «Сохранить» делает копию всех данных одним файлом, а переключатель «Запускать вместе с Windows» включает работу в фоне.

Если программа работает с облачным сайтом или проверка чатов стоит «по расписанию», она остаётся работать после закрытия окна. Нажатие на значок снова открывает окно, а полностью остановить программу можно кнопкой «Закрыть программу» внизу профиля.

### Как устроено окно программы

- **Первая настройка** подсказывается прямо в ленте: сверху плашка «Настройка: шаг N из 5». Порядок: ИИ, Telegram, чаты, бот на телефон, сайт на телефон. Кнопка «Позже» прячет плашку на сутки.
- **На широком экране** слева меню, посередине список заказов, справа открытый заказ с черновиком. Клавиши: `J`/`K` следующий и предыдущий заказ, `S` отложить, `U` подходит, `D` не подходит, `/` поиск, `R` проверить чаты, `Esc` закрыть заказ.
- **Профиль** разделён на «Обо мне», «Чаты», «Подключения» и «Программа».
- **«Отброшено»** подписывает, кто и почему решил, что сообщение не заказ («ИИ: предложение услуг», «по правилам: правила чата»). Ошиблись, нажмите «Это заказ»: ИИ запомнит это как пример.
- **Обучение ИИ**: «Это заказ», 👍 и 👎 с причиной «Это не заказ» становятся примерами в подсказке для ИИ. Показываются самые похожие на читаемые сообщения.
- **Обновление**: каждая правка программы автоматически собирается в новую версию. Вверху окна появляется полоса «Есть новая версия», нажимаете «Обновить».

Ниже запасные способы запуска.

## A. На своём компьютере из файлов проекта (без установщика)

1. Установите Python 3.11 или новее с https://www.python.org/downloads/ (в Windows поставьте галочку «Add python.exe to PATH»).
2. Скачайте проект (кнопка Code → Download ZIP на странице репозитория) и распакуйте в любую папку.
3. Запустите двойным щелчком:
   - **Windows**: `start-windows.bat`
   - **Mac**: `start-mac.command` (если система не даёт открыть: правый клик → «Открыть»)
   - **Linux**: `start-linux.sh`
   Первый раз программа сама подготовится, это займёт пару минут и потребует интернет.
4. Откроется браузер со Scout. Пароль не нужен: приложение доступно только с этого компьютера.
5. Нажмите **«Проверить чаты»**: бот прочитает чаты, разберёт всё накопленное и покажет заказы. ИИ (если подключён) уточнит оценки сразу после этого, пока окно открыто.
6. Закройте окно, и программа остановится сама примерно через 2 минуты. Данные хранятся в папке `.leadscout` в вашей домашней папке, поэтому при следующем запуске всё на месте.
7. Хотите отдельное окно с иконкой: в Chrome или Edge откройте меню → «Установить приложение» (на странице Scout). Но запускать программу всё равно нужно файлом из пункта 3.

Подключение Telegram, бота и ИИ делается так же, как описано ниже (шаги 5–9). Если вам нужна проверка по расписанию, выберите в «Профиль → Чаты → как часто проверять» интервал вместо «Вручную»: тогда программа сама проверяет чаты, пока открыта.

Важно: если вы живёте в России, Gemini с домашнего интернета может не работать, нужен VPN или другой ИИ (Groq, OpenRouter, своя модель). Ограничения Telegram проверьте на месте.

## A+. Свой сайт в облаке (Cloudflare) + программа на компьютере

Как это устроено: на Cloudflare живёт сайт и база данных, а чаты читает и ИИ запускает программа Scout на вашем компьютере и присылает туда результат. С телефона вы открываете сайт, видите заказы, ставите оценки, сохраняете и отмечаете отклики. Эти действия ждут в очереди и выполняются на компьютере, когда программа запущена. Пока компьютер выключен, сайт показывает последние присланные данные и честно пишет «Компьютер не в сети». Ключи Telegram, бота и ИИ в облако не попадают, они остаются только на компьютере.

Что нужно один раз:

1. Бесплатный аккаунт на https://dash.cloudflare.com/sign-up (карта не нужна).
2. Установленный Node.js (https://nodejs.org, версия LTS).
3. В папке проекта откройте терминал и выполните:
   ```
   cd cloud
   npm install
   npm run setup
   ```
   Мастер сам откроет браузер для входа в Cloudflare, создаст базу `scout`, спросит пароль для сайта (Enter: придумает сам), создаст ключ синхронизации и опубликует сайт. В конце он напечатает **адрес сайта**, **пароль** и **ключ синхронизации** (они же сохранены в `cloud/.scout-secrets.json`, файл никому не показывайте).
4. Запустите программу на компьютере (раздел A). Откройте «Профиль → Подключения → Облачный сайт», вставьте адрес и ключ синхронизации, нажмите «Подключить».
5. Откройте адрес сайта на телефоне, войдите паролем и поставьте сайт на экран «Домой» (раздел 4 ниже).

**Вариант без командной строки: подключить репозиторий прямо на сайте Cloudflare.**

1. На https://dash.cloudflare.com откройте «Workers & Pages» → «Create» → «Import a repository» (подключение к GitHub), разрешите Cloudflare доступ к репозиторию `lead-scout` и выберите его.
2. Заполните поля: **Project name** `scout` (именно так), **Production branch** ветка, из которой собираете (например `claude/busy-goodall-2tufgm` или `main`), **Root directory** `cloud`, **Build command** `node scripts/prepare.mjs`, **Deploy command** `npx wrangler deploy`.
3. Нажмите «Save and Deploy». Базу данных `scout` Cloudflare создаст сам при первой публикации (в `cloud/wrangler.toml` её идентификатор намеренно не указан).
4. Откройте созданный Worker → «Settings» → «Variables and Secrets» → «Add», тип **Secret**, и добавьте два секрета: `APP_PASSWORD` (пароль входа на сайт, от 8 символов) и `SYNC_TOKEN` (длинный случайный ключ от 32 символов: придумайте или сгенерируйте любым генератором паролей). Нажмите «Deploy».
5. Адрес сайта (вида `https://scout.имя.workers.dev`) показан на странице Worker. Дальше пункт 4 из списка выше: вставьте адрес и `SYNC_TOKEN` в программе на компьютере.

Если публикация пишет, что не нашла базу данных, создайте её вручную: Cloudflare → «Storage & Databases» → «D1» → «Create», имя `scout`, и впишите её ID в `cloud/wrangler.toml` строкой `database_id = "…"` под строкой `database_name`.

Какие секреты нужны в Cloudflare: только два, `APP_PASSWORD` (пароль входа на сайт) и `SYNC_TOKEN` (ключ, которым компьютер доказывает облаку, что это он). Мастер задаёт оба сам. Вручную это делается командами `npx wrangler secret put APP_PASSWORD` и `npx wrangler secret put SYNC_TOKEN`. Больше ничего в Cloudflare вводить не надо.

Как пользоваться: программа на компьютере должна быть запущена (чёрное окно открыто), чтобы действия с телефона доходили и чтобы чаты читались. Если выбрана проверка «Вручную», кнопка «Проверить чаты» есть и на сайте: она ставит команду в очередь, и компьютер выполнит её, когда запущен. Для круглосуточной работы выберите в программе проверку по расписанию, например раз в час. Подключения (Telegram, бот, ИИ), выбор чатов и ключи меняются только в программе на компьютере, на сайте они показаны для справки.

Переустановка или обновление сайта: снова `cd cloud && npm run setup` (пароль и ключ останутся прежними). Бесплатного тарифа Cloudflare хватает с большим запасом: программа обращается к сайту раз в 20 секунд, а присылает только изменившееся.

Важно знать: на сайте видны заказы за последние 14 дней (не больше 2500), а вся история хранится на компьютере. Черновики откликов на сайте готовятся программой заранее (по два варианта в трёх тонах), поэтому «Переписать» на сайте перебирает готовые тексты и сам ИИ не вызывает. Живой запуск на вашем аккаунте Cloudflare я проверить не мог: я проверял настоящий локальный Cloudflare (workerd) вместе с программой, а установку мастером нужно пройти у вас. Если мастер остановится с ошибкой, пришлите её текст.

## B. На сервере


Цель: чтобы бот круглосуточно читал ваши Telegram-чаты, находил заказы и присылал их вам. Ниже порядок действий и что на каком шаге проверить.

## 0. Что понадобится (подготовьте заранее)

| Что | Где взять | Сколько стоит |
|---|---|---|
| Сервер (VPS) на Ubuntu 22.04 или 24.04, от 1 ГБ памяти | любой хостинг, лучше в Европе: оттуда доступны и Telegram, и Gemini | 300–600 ₽ в месяц |
| Домен или поддомен (например `scout.вашдомен.ru`) | любой регистратор | около 200–1000 ₽ в год |
| Telegram-аккаунт, который состоит в нужных чатах | у вас есть | бесплатно |
| Ключи Telegram `api_id` и `api_hash` | https://my.telegram.org/apps | бесплатно |
| Бот в Telegram (токен) | @BotFather, команда `/newbot` | бесплатно |
| Ключ Google Gemini (для ИИ, по желанию) | https://aistudio.google.com/apikey | бесплатный тариф |

Совет: для чтения чатов лучше завести отдельный аккаунт Telegram и вступить им в нужные чаты. Бот только читает, но массовая автоматика на основном аккаунте всегда небольшой риск.

## 1. Сервер и домен

1. Купите VPS и получите его IP-адрес и пароль или SSH-ключ.
2. В настройках домена создайте запись типа **A**: имя вашего поддомена → IP сервера. Подождите 5–30 минут.
3. Подключитесь к серверу: `ssh root@IP-СЕРВЕРА`.
4. Установите Docker одной командой: `curl -fsSL https://get.docker.com | sh`.
5. На сервере должны быть открыты порты 80 и 443 (у большинства хостингов открыты по умолчанию).

## 2. Скачать и настроить

```bash
git clone -b claude/busy-goodall-2tufgm https://github.com/maxbzd/lead-scout.git
cd lead-scout
cp .env.example .env
nano .env
```

Если репозиторий приватный, Git попросит логин GitHub и токен (GitHub → Settings → Developer settings → Personal access tokens).
Ветку `claude/busy-goodall-2tufgm` можно заменить на `main`, когда вы объедините изменения.

В файле `.env` замените:
- `LS_DOMAIN` и `LS_PUBLIC_URL` на ваш домен (оба, `LS_PUBLIC_URL` с `https://`);
- `LS_PASSWORD` на свой длинный пароль (им вы входите в приложение);
- `LS_TZ` на ваш часовой пояс, например `Europe/Moscow`.

Сохраните: в nano `Ctrl+O`, `Enter`, `Ctrl+X`.

## 3. Запустить

```bash
docker compose up -d --build
docker compose logs -f scout
```

В логах должно быть `Application startup complete`. Выйти из просмотра: `Ctrl+C` (бот продолжит работать).
Откройте `https://ваш-домен`, введите пароль из `.env`. Первый раз сертификат выпускается до минуты.

Если страница не открывается: проверьте запись домена (`ping ваш-домен` должен показать IP сервера) и открытые порты 80 и 443.

## 4. Поставить на телефон

- **iPhone**: откройте сайт в Safari → «Поделиться» → «На экран Домой».
- **Android**: Chrome → меню → «Установить приложение».

## 5. Подключить Telegram (Профиль → Подключения → Telegram)

1. На https://my.telegram.org/apps войдите по номеру телефона, нажмите «Create application» (название любое, например Scout).
2. Скопируйте в приложение `api_id` (число) и `api_hash` (32 символа).
3. Введите номер телефона аккаунта. Код придёт **в приложение Telegram**, в чат «Telegram». Введите его.
4. Если включена двухфакторная защита, введите облачный пароль.
5. В списке устройств Telegram появится «Lead Scout»: так и должно быть.

Проверка: в приложении у Telegram статус «подключён», демо-заказы исчезли.

## 6. Подключить бота-уведомителя (Профиль → Подключения → Бот)

1. В Telegram откройте @BotFather, `/newbot`, придумайте имя и адрес (оканчивается на `bot`).
2. Вставьте токен в приложение. Затем откройте своего бота и нажмите **Start**: так он поймёт, что вы хозяин.

Проверка: бот пришлёт «подключён». Команды: `/digest`, `/stats`, `/chats`, `/add`, `/pause`, `/app`.

## 7. Выбрать чаты (Профиль → Управлять чатами)

- «Показать мои чаты» и добавьте нужные, или вставьте ссылки.
- **Начните с 5–10 чатов**: так проще оценить качество и расход, потом добавите остальные.

**Как часто проверять.** В «Профиле» в блоке «Чаты» выберите частоту: 10 минут, 30, 1 час, 2 часа или 6 часов. Для оживлённых чатов хватает часа: бот каждый раз читает всё накопленное (до 8000 сообщений на чат за проверку), ничего не теряется, а расход ИИ и нагрузка падают. При интервале от 30 минут бот не разбирает сообщения по одному, а делает это пачкой при проверке.

## 8. Заполнить профиль (Профиль)

- Навыки, минимальный бюджет, ставка за день, стоп-слова, 1–3 примера работ, о себе, тон откликов. Если есть резюме, нажмите «Собрать из текста».
- Оставьте включённым «Ничего не пропускать».
- Уведомления: тихие часы, утренняя сводка, итоги недели. Время сводки по вашему часовому поясу.

## 9. Включить ИИ (Профиль → Подключения → ИИ)

1. Выберите «Google Gemini (бесплатно)», вставьте ключ из Google AI Studio.
2. Нажмите «Показать доступные модели» и выберите оттуда Flash-Lite или другую лёгкую модель (названия у Google меняются).
3. «Проверить и подключить»: приложение сделает один пробный запрос.
4. Включите автопаузу (по умолчанию 40 неразобранных заказов): когда лента заполнена, ИИ перестаёт тратить запросы.

Без ИИ всё работает по правилам, ИИ только уточняет оценки.

## 10. Проверка, что всё работает (10 минут)

1. **Живое чтение.** Создайте закрытую группу в Telegram, где только вы, добавьте её в «Управлять чатами» и напишите туда, например: «Нужен телеграм-бот с GPT для записи клиентов. Бюджет 40 000 ₽, срок 7 дней. @ваш_ник». Через несколько секунд заказ должен появиться в ленте (с другого аккаунта, не с того, что подключён: свои сообщения бот не считает заказами).
2. **Уведомления.** Новый хороший заказ приходит в бот. Нажмите 👍 или 👎 в боте и убедитесь, что в приложении оценка отразилась.
3. **Проверка чатов.** Нажмите значок сканирования вверху: должно появиться «прочитано N».
4. **Ошибки чатов.** Если у чата красная строка, там причина (закрытый чат, вас убрали).
5. **Расход ИИ.** «Профиль → ИИ» показывает запросов за сегодня.

Если что-то из этого не сработало, скопируйте текст ошибки из `docker compose logs --tail 100 scout`.

## 11. Первые дни

- Ставьте 👍/👎 всем заказам: так бот учится, а «Аналитика» показывает точность.
- Раз в день заглядывайте в «Отброшено» и «Отсеянные»: если там что-то нужное, нажмите «Это заказ» или 👍.
- Когда убедитесь, что качество устраивает, добавляйте остальные чаты.

## 12. Обслуживание

```bash
cd lead-scout
git pull && docker compose build --pull && docker compose up -d   # обновление (--pull берёт свежие образы с исправлениями безопасности)
docker compose logs --tail 100 scout          # последние записи журнала
docker compose restart scout                  # перезапуск
```

**Резервная копия.** Всё важное лежит в томе Docker (база, ключи, сессия Telegram, файл `secret.key`):
```bash
docker volume ls                              # найдите том с именем ..._scout-data
docker run --rm -v ИМЯ_ТОМА:/data -v "$PWD":/backup alpine tar czf /backup/scout-backup.tgz /data
```
Храните копию в безопасном месте. Без файла `secret.key` сохранённые ключи расшифровать нельзя: придётся подключить Telegram, бота и ИИ заново.

**Забыли пароль:** впишите новый в `LS_PASSWORD` в `.env` и выполните `docker compose up -d`.

## 13. Частые вопросы

- **«Telegram разлогинил аккаунт».** Нажмите «Войти» в баннере ленты и пройдите вход заново.
- **Не приходят уведомления.** Нажали ли вы Start у бота? Не включена ли «Пауза» в уведомлениях? Не тихие ли сейчас часы?
- **Бот пропустил заказ.** Посмотрите «Отброшено» и «Отсеянные». Если нашли, нажмите «Это заказ» и пришлите мне текст сообщения: я подправлю правила.
- **ИИ «на паузе».** Либо вы включили паузу, либо накопилось много неразобранных заказов. Разберите ленту или поднимите порог.
