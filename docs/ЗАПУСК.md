# Запуск Scout: всё по шагам

Цель: чтобы бот круглосуточно читал ваши Telegram-чаты, находил заказы и присылал их вам. Ниже порядок действий и что на каком шаге проверить.

## 0. Что понадобится (подготовьте заранее)

| Что | Где взять | Сколько стоит |
|---|---|---|
| Сервер (VPS) на Ubuntu 22.04 или 24.04, от 1 ГБ памяти | любой хостинг, лучше в Европе: оттуда доступны и Telegram, и Gemini | 300–600 ₽ в месяц |
| Домен или поддомен (например `scout.вашдомен.ru`) | любой регистратор | около 200–1000 ₽ в год |
| Telegram-аккаунт, который состоит в нужных чатах | у вас есть | бесплатно |
| Ключи Telegram `api_id` и `api_hash` | https://my.telegram.org/apps | бесплатно |
| Бот в Telegram (токен) | @BotFather, команда `/newbot` | бесплатно |
| Ключ Google Gemini (для ИИ, по желанию) | https://aistudio.google.com/apikey | бесплатный тариф |

Совет: для чтения чатов лучше завести отдельный аккаунт Telegram и вступить им в нужные чаты. Бот только читает, но массовая автоматика на основном аккаунте всегда небольшой риск.

## 1. Сервер и домен

1. Купите VPS и получите его IP-адрес и пароль или SSH-ключ.
2. В настройках домена создайте запись типа **A**: имя вашего поддомена → IP сервера. Подождите 5–30 минут.
3. Подключитесь к серверу: `ssh root@IP-СЕРВЕРА`.
4. Установите Docker одной командой: `curl -fsSL https://get.docker.com | sh`.
5. На сервере должны быть открыты порты 80 и 443 (у большинства хостингов открыты по умолчанию).

## 2. Скачать и настроить

```bash
git clone -b claude/busy-goodall-2tufgm https://github.com/maxbzd/lead-scout.git
cd lead-scout
cp .env.example .env
nano .env
```

Если репозиторий приватный, Git попросит логин GitHub и токен (GitHub → Settings → Developer settings → Personal access tokens).
Ветку `claude/busy-goodall-2tufgm` можно заменить на `main`, когда вы объедините изменения.

В файле `.env` замените:
- `LS_DOMAIN` и `LS_PUBLIC_URL` на ваш домен (оба, `LS_PUBLIC_URL` с `https://`);
- `LS_PASSWORD` на свой длинный пароль (им вы входите в приложение);
- `LS_TZ` на ваш часовой пояс, например `Europe/Moscow`.

Сохраните: в nano `Ctrl+O`, `Enter`, `Ctrl+X`.

## 3. Запустить

```bash
docker compose up -d --build
docker compose logs -f scout
```

В логах должно быть `Application startup complete`. Выйти из просмотра: `Ctrl+C` (бот продолжит работать).
Откройте `https://ваш-домен`, введите пароль из `.env`. Первый раз сертификат выпускается до минуты.

Если страница не открывается: проверьте запись домена (`ping ваш-домен` должен показать IP сервера) и открытые порты 80 и 443.

## 4. Поставить на телефон

- **iPhone**: откройте сайт в Safari → «Поделиться» → «На экран Домой».
- **Android**: Chrome → меню → «Установить приложение».

## 5. Подключить Telegram (Профиль → Подключения → Telegram)

1. На https://my.telegram.org/apps войдите по номеру телефона, нажмите «Create application» (название любое, например Scout).
2. Скопируйте в приложение `api_id` (число) и `api_hash` (32 символа).
3. Введите номер телефона аккаунта. Код придёт **в приложение Telegram**, в чат «Telegram». Введите его.
4. Если включена двухфакторная защита, введите облачный пароль.
5. В списке устройств Telegram появится «Lead Scout»: так и должно быть.

Проверка: в приложении у Telegram статус «подключён», демо-заказы исчезли.

## 6. Подключить бота-уведомителя (Профиль → Подключения → Бот)

1. В Telegram откройте @BotFather, `/newbot`, придумайте имя и адрес (оканчивается на `bot`).
2. Вставьте токен в приложение. Затем откройте своего бота и нажмите **Start**: так он поймёт, что вы хозяин.

Проверка: бот пришлёт «подключён». Команды: `/digest`, `/stats`, `/chats`, `/add`, `/pause`, `/app`.

## 7. Выбрать чаты (Профиль → Управлять чатами)

- «Показать мои чаты» и добавьте нужные, или вставьте ссылки.
- **Начните с 5–10 чатов**: так проще оценить качество и расход, потом добавите остальные.

**Как часто проверять.** В «Профиле» в блоке «Чаты» выберите частоту: 10 минут, 30, 1 час, 2 часа или 6 часов. Для оживлённых чатов хватает часа: бот каждый раз читает всё накопленное (до 8000 сообщений на чат за проверку), ничего не теряется, а расход ИИ и нагрузка падают. При интервале от 30 минут бот не разбирает сообщения по одному, а делает это пачкой при проверке.

## 8. Заполнить профиль (Профиль)

- Навыки, минимальный бюджет, ставка за день, стоп-слова, 1–3 примера работ, о себе, тон откликов. Если есть резюме, нажмите «Собрать из текста».
- Оставьте включённым «Ничего не пропускать».
- Уведомления: тихие часы, утренняя сводка, итоги недели. Время сводки по вашему часовому поясу.

## 9. Включить ИИ (Профиль → Подключения → ИИ)

1. Выберите «Google Gemini (бесплатно)», вставьте ключ из Google AI Studio.
2. Нажмите «Показать доступные модели» и выберите оттуда Flash-Lite или другую лёгкую модель (названия у Google меняются).
3. «Проверить и подключить»: приложение сделает один пробный запрос.
4. Включите автопаузу (по умолчанию 40 неразобранных заказов): когда лента заполнена, ИИ перестаёт тратить запросы.

Без ИИ всё работает по правилам, ИИ только уточняет оценки.

## 10. Проверка, что всё работает (10 минут)

1. **Живое чтение.** Создайте закрытую группу в Telegram, где только вы, добавьте её в «Управлять чатами» и напишите туда, например: «Нужен телеграм-бот с GPT для записи клиентов. Бюджет 40 000 ₽, срок 7 дней. @ваш_ник». Через несколько секунд заказ должен появиться в ленте (с другого аккаунта, не с того, что подключён: свои сообщения бот не считает заказами).
2. **Уведомления.** Новый хороший заказ приходит в бот. Нажмите 👍 или 👎 в боте и убедитесь, что в приложении оценка отразилась.
3. **Проверка чатов.** Нажмите значок сканирования вверху: должно появиться «прочитано N».
4. **Ошибки чатов.** Если у чата красная строка, там причина (закрытый чат, вас убрали).
5. **Расход ИИ.** «Профиль → ИИ» показывает запросов за сегодня.

Если что-то из этого не сработало, скопируйте текст ошибки из `docker compose logs --tail 100 scout`.

## 11. Первые дни

- Ставьте 👍/👎 всем заказам: так бот учится, а «Аналитика» показывает точность.
- Раз в день заглядывайте в «Отброшено» и «Отсеянные»: если там что-то нужное, нажмите «Это заказ» или 👍.
- Когда убедитесь, что качество устраивает, добавляйте остальные чаты.

## 12. Обслуживание

```bash
cd lead-scout
git pull && docker compose build --pull && docker compose up -d   # обновление (--pull берёт свежие образы с исправлениями безопасности)
docker compose logs --tail 100 scout          # последние записи журнала
docker compose restart scout                  # перезапуск
```

**Резервная копия.** Всё важное лежит в томе Docker (база, ключи, сессия Telegram, файл `secret.key`):
```bash
docker volume ls                              # найдите том с именем ..._scout-data
docker run --rm -v ИМЯ_ТОМА:/data -v "$PWD":/backup alpine tar czf /backup/scout-backup.tgz /data
```
Храните копию в безопасном месте. Без файла `secret.key` сохранённые ключи расшифровать нельзя: придётся подключить Telegram, бота и ИИ заново.

**Забыли пароль:** впишите новый в `LS_PASSWORD` в `.env` и выполните `docker compose up -d`.

## 13. Частые вопросы

- **«Telegram разлогинил аккаунт».** Нажмите «Войти» в баннере ленты и пройдите вход заново.
- **Не приходят уведомления.** Нажали ли вы Start у бота? Не включена ли «Пауза» в уведомлениях? Не тихие ли сейчас часы?
- **Бот пропустил заказ.** Посмотрите «Отброшено» и «Отсеянные». Если нашли, нажмите «Это заказ» и пришлите мне текст сообщения: я подправлю правила.
- **ИИ «на паузе».** Либо вы включили паузу, либо накопилось много неразобранных заказов. Разберите ленту или поднимите порог.
- **Лимит Gemini исчерпан.** До утра бот работает по правилам, это нормально.
- **Заказы приходят с задержкой.** Живые сообщения разбираются сразу, а раз в 10 минут бот проходит по чатам и подбирает пропущенное.

## 14. Что не проверено заранее

Живую работу с Telegram, Gemini и сборку Docker-образа я проверял только на подставных данных и заглушках. Поэтому первый запуск проходите по пункту 10 и сообщайте о любой странности вместе с текстом ошибки.
