# Scout — личный скаут фриланс-заказов из Telegram

Scout читает выбранные вами Telegram-чаты, находит заказы под ваши навыки (всё, что связано с ИИ),
отсеивает мошенников и «дёшево за большую работу», подсказывает, сколько просить, пишет черновик отклика
и присылает самое горячее в Telegram. Вы нажимаете 👍 или 👎, и он учится на ваших оценках.

Это сайт, который ставится на телефон как приложение (PWA). Работает у вас одного, по паролю.

## Что внутри

- **Лента заказов**: оценка совпадения, бюджет, срок, почему подходит, предупреждения о подозрительном.
- **Карточка заказа**: рекомендуемая цена, данные о заказчике, исходный текст, черновик отклика в трёх тонах.
  Кнопка «Откликнуться» копирует текст и открывает чат с заказчиком. Сам бот ничего не пишет от вашего имени.
- **Режим «Ничего не пропускать»** (включён по умолчанию, Профиль → переключатель сверху): бот лучше покажет лишнее, чем потеряет настоящий заказ.
  Короткие объявления и просьбы вроде «подскажите, кто делает ботов» попадают в ленту. Заказы ниже вашего минимума или со стоп-словом остаются
  в ленте с пометкой «на всякий случай». Уведомления приходят и о «возможно подойдёт». Всё, что бот не счёл заказом (болтовня, вакансии в штат,
  реклама), лежит в ленте в разделе **«Отброшено»**, откуда любое сообщение возвращается кнопкой «Это заказ». Отсеянное как мошенничество
  видно в «Отсеянных», а 👍 на таком заказе возвращает его в ленту. В утренней сводке бот пишет, сколько всего отсеяно.
- **Обучение**: 👍/👎 с причиной. Бот предлагает поднять минимальный бюджет или отключить шумный чат.
- **Аналитика**: точность подбора по неделям, воронка, когда появляются заказы, откуда лучшие.
- **Бот в Telegram**: свежие горячие заказы, утренняя сводка, итоги недели, кнопки оценки прямо в чате.
- **Подключения внутри приложения**: Telegram-аккаунт, бот и ключ Claude вводятся пошагово в разделе «Профиль».
- **Демо-режим**: пока ничего не подключено, видны тестовые заказы, чтобы понять, как всё работает.

Без ключа Claude бот работает по правилам (быстро и бесплатно). С ключом точнее понимает смысл и пишет живые отклики.

## Попробовать за минуту (на своём компьютере)

Нужен Python 3.11 или новее.

```bash
pip install .
python -m leadscout --demo
```

В терминале появится пароль. Откройте http://localhost:8000 и войдите.

## Поставить на сервер (чтобы работало круглосуточно)

Подойдёт любой дешёвый VPS (от 300 ₽ в месяц) с Docker и свой домен, направленный на сервер.

1. Скопируйте проект на сервер и создайте настройки:
   ```bash
   cp .env.example .env
   nano .env      # впишите свой домен в LS_DOMAIN и LS_PUBLIC_URL, придумайте LS_PASSWORD
   ```
2. Запустите:
   ```bash
   docker compose up -d
   ```
   Caddy сам получит бесплатный HTTPS-сертификат. Откройте `https://ваш-домен` и войдите.
3. Данные (база, ключи) лежат в томе Docker `scout-data`. Для резервной копии сохраните этот том.

Обновление: `git pull && docker compose up -d --build`.

## Подключить аккаунты (в приложении: Профиль → Подключения)

**1. Telegram-аккаунт** (чтобы читать чаты)
1. Откройте https://my.telegram.org/apps, войдите по номеру, нажмите «Create application» (название любое).
2. Скопируйте `api_id` и `api_hash` в приложение.
3. Введите номер телефона, затем код, который придёт в Telegram (и пароль, если включена двухфакторная защита).

Бот только читает. Он не пишет, не вступает в споры и не отправляет сообщений от вашего имени.
Читайте не более нескольких десятков чатов: Telegram не любит массовую автоматизацию.
Если хотите подстраховаться, войдите вторым аккаунтом, который состоит в нужных чатах.

**2. Бот в Telegram** (чтобы получать уведомления)
1. В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя и адрес.
2. Вставьте полученный токен в приложение и нажмите Start у своего бота: так он поймёт, что вы хозяин.

**3. Ключ Claude** (по желанию, для точности)
1. Откройте https://console.anthropic.com/settings/keys и создайте ключ.
2. Вставьте его в приложение. Расход зависит от числа чатов и их активности: для 10 чатов порядка 5–30 $ в месяц, для 50 чатов заметно больше (расчёт ниже). Фактическая сумма видна в «Аналитике».

Все ключи хранятся на вашем сервере в зашифрованном виде и никуда не отправляются, кроме самих сервисов.

## Поставить на телефон как приложение

- **iPhone**: откройте сайт в Safari → «Поделиться» → «На экран Домой».
- **Android**: Chrome → меню → «Установить приложение» (или кнопка в разделе «Профиль»).

Лента открывается и без интернета: показывается то, что сохранилось на телефоне.

## Настройки через `.env`

| Переменная | Что делает |
|---|---|
| `LS_PASSWORD` | пароль для входа (если пусто, создаётся сам и пишется в `data/password.txt`) |
| `LS_PUBLIC_URL` | адрес сайта, нужен для ссылок «Открыть в приложении» в Telegram |
| `LS_TZ` | часовой пояс |
| `LS_SCAN_MINUTES` | как часто проверять чаты (по умолчанию 10) |
| `LS_USD_RUB`, `LS_EUR_RUB` | курсы, чтобы сравнивать бюджеты в валюте |
| `ANTHROPIC_API_KEY`, `TELEGRAM_*` | можно задать здесь вместо ввода в приложении |

## Если что-то не работает

- **«Telegram разлогинил аккаунт»**: нажмите «Войти» в баннере или в Профиле и пройдите вход заново.
- **Не приходят уведомления**: проверьте, что вы нажали Start у бота и что не включена «Пауза» в Профиле.
- **Забыли пароль**: он в файле `/data/password.txt` внутри тома (или задайте новый `LS_PASSWORD` и перезапустите).
- **Чат не читается**: у чата в списке будет красная строка с причиной (закрытый, убрали из чата и т. п.).

## Для разработчиков

```bash
pip install -e ".[dev]"
pytest                                  # тесты
ruff check .                            # линтер Python
npx eslint -c eslint.config.js leadscout/web/static   # линтер JS
python scripts/make_icons.py            # перерисовать значки
python scripts/vendor_fonts.py          # заново скачать шрифты
```

Устройство: `pipeline.py` (сообщение → заказ), `scoring.py` и `learning.py` (оценка и обучение),
`llm/` (правила и Claude), `sources/` (Telegram и демо), `bot.py` и `notify.py` (бот),
`runtime.py` (расписание и подключения), `web/` (API и приложение).
